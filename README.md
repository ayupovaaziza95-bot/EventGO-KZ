## Project

## Tech Stack & Tools

* **Figma Make** — среда разработки и прототипирования
* **React** — UI-библиотека
* **TypeScript** — типизация
* **React Router** — маршрутизация
* **Tailwind CSS & PostCSS** — стилизация
* **shadcn/ui** — компоненты интерфейса
* **Vite** — сборщик проекта
* **pnpm** — пакетный менеджер
