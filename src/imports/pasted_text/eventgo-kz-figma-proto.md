# Полное ТЗ для Figma-прототипа приложения EventGO KZ

Создать полностью кликабельный прототип мобильного приложения EventGO KZ в Figma, используя в качестве рамки для всех экранов фрейм iPhone 16 Pro (393×852px) с Dynamic Island сверху и home indicator снизу. Прототип должен содержать минимум 20 экранов включая Overlay-фреймы, быть полностью кликабельным через инструмент Prototype в Figma, иметь логичную навигацию, отражать полный пользовательский путь от первого запуска до завершённого бронирования с жильём и картой маршрута, и поддерживать единый дизайн на всех экранах. Все фреймы расположить слева направо в порядке пользовательского флоу на канвасе Figma, подписать каждый фрейм снизу, а все переходы настроить через панель Prototype с анимацией Smart Animate или Push для горизонтальных переходов, Move In снизу для модальных окон и Dissolve для главных переходов.

## Пользовательский путь (User Flow)

Полный путь пользователя: Splash Screen → Экран входа/регистрации → Онбординг 1 → Онбординг 2 → Онбординг 3 → Главная → Поиск → Фильтры → Список событий → Карточка события → Планирование поездки → Выбор жилья → WebView Booking/Krisha → Карта маршрута → Выбор даты → Ввод данных → Оплата → Подтверждение → Мои поездки → Профиль → AI-рекомендации → Совместная поездка. Каждый экран соединён стрелками прототипирования, все кнопки, иконки таббара, карточки и ссылки кликабельны и ведут на соответствующий экран или Overlay.

## Технические правила интерактивности в Figma

Каждый интерактивный элемент должен быть компонентом — выделить, нажать Ctrl+Alt+K, затем на Instance ставить Prototype-соединение. Соединение ставится только на верхний слой: если кнопка — это группа из прямоугольника и текста, соединение на группу целиком. Таббар сделать одним Main Component с четырьмя Variant (Active: Home/Search/Trips/Profile), на каждом экране Instance с нужным вариантом, соединения на иконки ставить на Instance внутри фрейма. Overlay-фреймы (модалки, меню, Toast) — отдельные фреймы на канвасе, Open Overlay Centered или Bottom, включить «Close when clicking outside». Смена состояний сердца, чипов, чекбоксов — через Change To Variant того же компонента, не Navigate To. Стартовый фрейм — Экран 1 Splash, правая кнопка «Set as starting frame», Play для теста. Все Open Link URLs вставлять точно без пробелов. На отдельной странице «Design System» хранить цветовые стили, текстовые стили и Main Components всех кнопок, полей, чипов, карточек, таббара и аватаров с вариантами состояний Default/Focus/Active/Disabled/Pressed.
